    03 / PERSONALIZAÇÃO

    Temas de cores

    Paletas automáticas, predefinidas ou definidas pelo desenvolvedor.

    No Android 12 ou superior, a biblioteca Android pode usar a paleta dinâmica do papel de parede. Na Web, a paleta Sistema usa a cor AccentColor quando o navegador a expõe; caso contrário, mantém uma base neutra. O desenvolvedor sempre pode definir uma cor própria.

    04 / ELEMENTOS VISUAIS

    Ícones expressivos

    Ícones vetoriais com traço arredondado, sem fonte externa ou dependência de runtime.

    Use MinimalIcons.create(nome, opções) para criar um SVG acessível. O conjunto é independente e pode ser ampliado sem carregar uma biblioteca inteira de terceiros.
