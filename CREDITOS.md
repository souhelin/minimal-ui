# Créditos e atribuições

O Minimal UI é um projeto independente. Esta página identifica as referências e tecnologias de terceiros utilizadas como base ou inspiração.

## Inspiração de design

- **[Material Design 3](https://m3.material.io/)** — referência conceitual para padrões de interface, componentes, estados, acessibilidade e temas. O Minimal UI possui identidade visual própria, monocromática, e não é um produto oficial do Google nem é afiliado ao Google.

## Tecnologias utilizadas

- **[Jetpack Compose](https://developer.android.com/jetpack/compose)** — toolkit declarativo usado na implementação Android.
- **[Material 3 para Android (AndroidX)](https://developer.android.com/develop/ui/compose/designsystems/material3)** — componentes e sistema de tema usados como base na implementação Android.
- **HTML, CSS e JavaScript** — tecnologias padrão utilizadas na demonstração Web, sem framework externo.

## Recursos de terceiros

A implementação atual não identifica fontes externas, pacotes de ícones, imagens de bancos externos ou outros assets de terceiros incorporados à demonstração Web. Os símbolos usados nela são caracteres de texto.
