# Minimal Typography — Android font assets

This directory is reserved for the original, validated Minimal font binaries.

No TTF/OTF files are included yet. Do not copy or rename an unrelated typeface into this directory and do not add resource XML that references files that do not exist.

When Minimal Sans is approved, add Android-compatible font resources here, define the corresponding `font-family` XML, and verify the assets in a consuming Compose app with system font scaling and TalkBack. Keep font licensing and version metadata with the distributed assets.
