# Minimal Typography — Android font assets

This directory documents the planned Android font integration.

The actual Android resource directory will be `android/src/main/res/font/` once original, validated TTF/OTF binaries are ready. No font binaries are included yet. Do not copy or rename an unrelated typeface into that resource directory and do not add resource XML that references files that do not exist.

When Minimal Sans is approved, add Android-compatible font resources and family XML, then verify the assets in a consuming Compose app with system font scaling and TalkBack. Keep font licensing and version metadata with the distributed assets.
